# Nutrition & activity tracker (Persian web app)

Early-stage project: a Persian web app for calorie counting, BMI, food and activity logging, macros/protein and reports.

- Product + UX brief (problem, audience hypotheses, scope, IA, flows, calculation spec, data model, voice, creative direction, open decisions): [`docs/product-ux-brief.md`](docs/product-ux-brief.md)
- Competitor benchmark (global apps, AI loggers, Karafs and Iranian competitors, integration limits, calculation evidence): [`docs/benchmark.md`](docs/benchmark.md)
- **MVP app (نخودچی): [`app/`](app/README.md)** — installable PWA + small Node/SQLite sync server for a private group (invite code). Run, deploy and admin instructions are in `app/README.md`.

Status: private MVP built (brief §18). Food values are unreviewed estimates; clinical review is deferred by the owner.
