# Taste profile from the Vantori and Kondor collaboration

Use this as optional evidence about the originating user's taste. It is not a mandatory theme for other users or brands. Confirm relevance against the current request; do not ask the same preference questions repeatedly.

## Current diversity correction — 2026-10-03

The owner reports repetitive opening frames over hero imagery and requests different visual styles and patterns. This corrects any transfer of earlier full-width-photo, glass-navigation, inset-frame or aperture examples into a universal recipe. Keep the cinematic ambition, but derive visual treatment, hero structure and motion independently through [design diversity](design-diversity.md). Historical examples below remain scoped observations, not a preferred template. Do not rotate styles arbitrarily or reopen an explicitly approved direction.

## Current explicit motion preference — 2026-09-14

The owner rejected the MAKS test as simple and old-fashioned, and explicitly requested cinematic, modern, creative scroll-triggered motion with a wow effect across sites built by this skill. This supersedes any inference that restrained decorative movement is sufficient. Use [cinematic direction](cinematic-direction.md): choose a new signature transformation for each subject, not the MAKS palette, photography, or split layout. Keep actual facts and approved assets exact; composition and scene choreography have broad creative freedom. Narrow edits and explicit low-motion/static requests still keep their scope.

## How to transfer the taste without copying the sites

1. Extract the relationship the user values: clear image versus dull overlay; balanced visual weight versus technically aligned boxes; visible depth versus a detached-looking person.
2. Choose a new visual mechanism that satisfies that relationship in the current brand.
3. Keep factual constraints exact. Keep aesthetic defaults revisable.
4. Record new feedback at the right scope. One section's product-right placement does not make all future pages product-right.

The older collaborations suggest clarity of photography, confident typography, and deliberate spatial relationships. They do not prescribe a warm editorial theme or restrained motion for new brands; use the current cinematic default and the actual subject to determine imagery, intensity, pacing, and staging.

## Supersession examples: do not learn the wrong rule

- Patterns were removed from Vantori version one, then explicitly required for version two. The lesson is not “never use patterns.”
- A full-slide pattern experiment and oversized bottles were rejected. After restoring the earlier composition, a later request swapped text and image. The correct current state combined the restored treatment with the later narrow change.
- The user wanted a honey section to fill the viewport and also wanted its opening-frame scale effect retained. Those requirements were compatible; removing the effect was an implementation regression.
- The video moved earlier, then later replaced a collection-introduction section. Track the final sequence rather than treating every earlier request as still active.
- A gray screenshot annotation first identified a frame boundary. A later instruction explicitly removed the stroke and requested a pale fill. The latest instruction defines the frame treatment.

## Design freedom versus fidelity

Keep exact: approved logo, product labeling, product identity, true material opacity, required recurring brand motifs, approved consumer copy, and supported claims.

Explore: hero structures, typographic/graphic/media relationships, visual treatment, scene selection, editorial rhythm, product staging, transitions and section sequencing. A frame opening is only one available composition, not the template for these explorations.

Do not import Vantori's drink imagery, Kondor's audience, either brand's slogan, fixed pixel sizes, or a past deployment destination into an unrelated project. They are examples, not defaults.
