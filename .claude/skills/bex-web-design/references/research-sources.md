## Motion implementation and inspiration

Checked 2026-09-14. The cinematic default is the owner's stated creative requirement, not a trend ranking or a usability finding. The following are primary implementation references and source-readable examples. Do not infer successful runtime behavior in a new project merely because a demo exists.

- **M1 — implementation:** [GSAP ScrollTrigger](https://gsap.com/docs/v3/Plugins/ScrollTrigger/) and [common mistakes](https://gsap.com/resources/st-mistakes/): scroll-controlled timelines, pinning constraints, geometry refresh, and ownership.

- **M3 — implementation:** [Flip.from](https://gsap.com/docs/v3/Plugins/Flip/static.from()/): shared-element continuity across layout states; absolute-positioning and nested-element considerations.
- **M4 — technique example:** [GSAP Scrubbed Bento Gallery](https://demos.gsap.com/demo/scrubbed-bento-gallery/) and [official CodePen source](https://codepen.io/GreenSock/pen/vYMzKZx): source describes a pinned, scrubbed layout transformation. - **M5 — technique example:** [GSAP ScrollTrigger mask-size](https://codepen.io/GreenSock/pen/RwmOvqE): source demonstrates an expanding aperture. Adapt the shape, pin spacing, dimensions, and timing; do not copy development markers into a final site.

## Evidence from local evaluation

The **2026-09-22 visual-foundation and open-source reuse extension** has a separate [source map](design-system-sources.md) covering Material 3, Apple HIG, Atlassian, Salesforce, the supplied TapTap kit, and actual component/icon libraries. Read it for evidence and access limits; it is not a mandatory web-research step on every edit. The user's reported spacing, grid, hierarchy, icon, and material weaknesses motivated stronger implementation rules. No specific failing website or comparative before/after website trial was inspected during that extension.

The version 1.0 trial built a fictional Persian page, preserved product geometry and a narrow column swap, and passed functional browser checks. A decorative label was visibly clipped midway through its frame animation. This supports retaining midpoint visual evidence; it does not prove that all clipping is faulty or that a new version improves conversion. The skill's new evidence checks generalize the verification lesson, not the particular brand or label.

Keep test fixtures and trial reports outside the installed skill. If later evidence contradicts a recommendation, update the relevant instruction and source record; do not accumulate competing rules.

The MAKS 1.2.0 trial passed functional checks but the owner explicitly rejected its creative direction as too simple and old-fashioned. It relied mainly on a static split hero, small image parallax/zoom, and a sticky editorial scene. This is direct feedback about that result; together with the owner's explicit cross-project request it motivates the cinematic default and a separate creative gate. It does not prove that these patterns are universally bad or that version 1.3.0 will necessarily impress every viewer.
